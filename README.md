# Agenda Escolar 

## Sobre o projeto

O **Agenda Escolar** é uma aplicação web desenvolvida para facilitar a organização e a solicitação de atendimentos pedagógicos no ambiente escolar.

A proposta é substituir processos manuais por uma interface digital simples, organizada e fácil de utilizar.

##  Objetivo

Facilitar o agendamento de atendimentos pedagógicos, ajudando os estudantes a organizar seus horários e consultar seus agendamentos.

##  Funcionalidades

- Solicitação de agendamentos.
- Preenchimento de nome, turma, motivo, data e horário.
- Visualização dos agendamentos cadastrados.
- Cancelamento de agendamentos.
- Verificação de horários já ocupados no mesmo navegador, caso essa validação esteja ativada.
- Armazenamento dos dados no navegador por meio do LocalStorage.

##  Tecnologias utilizadas

- **HTML5:** estrutura da aplicação.
- **CSS3:** aparência visual e responsividade.
- **JavaScript:** funcionalidades e interatividade.
- **LocalStorage:** armazenamento local dos agendamentos.
- **Git e GitHub:** versionamento e hospedagem do código.

##  Observação

Esta versão é um protótipo front-end. Os agendamentos ficam armazenados somente no navegador utilizado e não são compartilhados entre diferentes dispositivos ou usuários.
